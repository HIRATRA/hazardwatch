# Security Policy

## Supported versions

HazardWatch is in early development. Only the latest commit on `main`
receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities through
[GitHub private vulnerability reporting](../../security/advisories/new).
Include a description of the issue, steps to reproduce and the impact you
expect. You should receive an acknowledgement within 72 hours.

## Scope

In scope: the web application, the ingestion worker, the database package
and the default deployment configuration in this repository.

Out of scope: vulnerabilities in third-party data providers and issues that
require a compromised host or leaked credentials.
